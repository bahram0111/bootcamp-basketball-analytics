# Basketball Data Analysis Project



This mini-project was completed as part of the Quera Data Analysis Bootcamp.



We scraped data from \[Basketball-Reference](https://www.basketball-reference.com/) and designed a database using the collected data. We then performed data preprocessing, exploratory data analysis (EDA), and statistical tests to answer the assigned research questions.
